## Contract priorities

| Contract          | Priority | Guarantee                                                                 |
| ----------------- | -------- | ------------------------------------------------------------------------- |
| cssRendering      | high     | Rendered classes have matching computed CSS.                              |
| sourceUpdate      | high     | Edits update CSS with the framework's ordinary reload and state behavior. |
| serverRendering   | high     | Fresh server HTML receives current CSS and agrees with client classes.    |
| interactions      | high     | Hydration and component interactions remain functional.                   |
| navigation        | high     | Navigation loads the destination's styles.                                |
| semantics         | high     | Composition and conditional styles preserve their behavior.               |
| buildInvalidation | high     | Rebuilds and restored producers emit current CSS.                         |
| sourceMaps        | low      | Generated classes map to their original macro positions.                  |
