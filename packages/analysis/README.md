# @stillwind/analysis

[Stillwind](https://stillwind.dev/) compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when AI agents write much of it.

`@stillwind/analysis` provides analysis and formatting services for Stillwind's CLI, language server, and
browser editors. Its Node, browser, and memory entrypoints adapt these services to their hosts.

See [Analysis contracts](https://github.com/SegaraRai/stillwind/blob/main/docs/standalone-analysis.md)
for configuration, service lifetimes, and embedding.
