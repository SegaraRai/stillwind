# @stillwind/projection

Stillwind compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when
AI agents write much of it.

`@stillwind/projection` prepares original source documents and coordinate mappings
for Stillwind compilation and TypeScript checks, including Vue, Svelte, and Astro
component documents.

See [SFC type checking](https://github.com/SegaraRai/stillwind/blob/main/docs/sfc-type-checking.md)
for converters, dependencies, and coordinate contracts.
