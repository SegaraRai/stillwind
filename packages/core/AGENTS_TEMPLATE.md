## Stillwind

- This project styles elements with [Stillwind](https://stillwind.dev/). Stillwind compiles Tailwind CSS v4 utilities in `style()` calls into element props and static CSS.
- Before you change styles, read the relevant Markdown docs in `node_modules/stillwind/docs/`. Start with `guides/recommended-practices.md`. `node_modules/stillwind/skills/stillwind/SKILL.md` lists the page for each task.
- After you change styles, run `stillwind lint --fix` and `stillwind fmt` through the project's package manager, and fix the remaining findings.
