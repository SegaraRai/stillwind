# Transforms, filters, and composited rendering

## `effects.transforms-and-filters`

### Input CSS

```css
@import "tailwindcss/theme" layer(theme);
@import "tailwindcss/utilities" layer(utilities);
```

### Candidates

```text
translate-x-4 -translate-y-1 scale-105 rotate-3 skew-x-3 origin-center blur-sm brightness-110 backdrop-blur-sm will-change-transform transform-gpu
```
