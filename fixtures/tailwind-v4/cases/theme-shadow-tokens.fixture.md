# Theme-defined shadow utility tokens

## `theme-shadow-tokens.custom-default-size-overrides`

### Input CSS

```css
@import "tailwindcss/theme" layer(theme);
@import "tailwindcss/utilities" layer(utilities);
@theme {
  --shadow-lg: 0 0 1px rgb(255 0 0 / 0.4), 0 0 3px rgb(0 0 255 / 0.2);
  --inset-shadow-sm: inset 0 0 2px rgb(0 128 0 / 0.3);
  --drop-shadow-sm: 0 0 4px rgb(128 0 128 / 0.5);
}
```

### Candidates

```text
shadow-lg inset-shadow-sm drop-shadow-sm
```

## `theme-shadow-tokens.namespace-removal`

```css
@import "tailwindcss/theme" layer(theme);
@import "tailwindcss/utilities" layer(utilities);
@theme {
  --shadow-*: initial;
  --inset-shadow-*: initial;
  --drop-shadow-*: initial;
}
```

### Candidates

```text
shadow-xs shadow-lg inset-shadow-xs inset-shadow-sm drop-shadow-xs drop-shadow-sm
```

### Expected CSS

```css
/*! tailwindcss v4.3.3 | MIT License | https://tailwindcss.com */
@layer utilities;
```
