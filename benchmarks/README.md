# Benchmarks

Stillwind compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when
AI agents write much of it.

This package contains Stillwind's private compiler, host, sorting, and source-map
benchmarks.

See [Development](DEVELOPMENT.md) for commands and measurement boundaries, and
[Performance budgets](performance/DEVELOPMENT.md) for regression limits.
