# Stillwind website

The Astro site uses the workspace Stillwind integration and compiles its component styles from
`src/styles.css`. The integration injects compiled CSS into each document. The displayed diagnostics
and CSS are generated by the compiler at build time.

Run tasks from the repository root:

```sh
vp run @stillwind-internal/apps-website#dev
vp run @stillwind-internal/apps-website#build
vp run @stillwind-internal/apps-website#preview
vp run @stillwind-internal/apps-website#typecheck
vp run @stillwind-internal/apps-website#test
vp run @stillwind-internal/apps-website#verify
```

Development and preview use port 4322. The build writes a static site to `dist/`.

The application provides emnapi 1.x for Astro's checker. Stillwind's compiler bindings use their
own emnapi 2.x dependency.

`src/lib/scroll.ts` publishes normalized progress as `--scroll-progress`. `src/lib/code-morph.ts`
matches whole tokens within stable utility keys and publishes `--morph-progress`. Only spaces and
variant colons divide utility strings. CSS interpolates the measured positions, colors, and visibility
of those tokens. Utility wrappers keep variants and colons on one line and supply continuous
underlines. Each compiler report identifies its utility from the reported source range. Diagnostic
lines start just below the center of that utility's underline and follow its measured position.
Multiple explanations occupy separate horizontal ranges. Tracking uses passive events and one
animation frame per update. Both controllers release their browser subscriptions on disposal.

The four scenes contain six complete states. Normalize & Format shows Original, Normalized, and
Formatted expressions at the same position under one heading. Normalization replaces `px-[16px]`
with the compiler's canonical utility, and formatting sorts the utilities. Compile uses the full
canvas width for its input. Its output row places React props and CSS together below the input.
An independent overlay draws the arrow without affecting the output columns.
Each interval holds its starting and ending states for 30% each. The remaining 40% drives the
transition, so complete states occupy 60% of the scroll range. Navigation moves smoothly to each
complete state, and ordinary scrolling follows the user's input.
The code remains selectable as the nearest complete source state.

The sticky presentation requires a viewport of at least 960 × 650 pixels and no reduced-motion
preference. Smaller viewports, reduced motion, and disabled JavaScript show the specimens in order.
Static findings place each marked utility and its connected explanation on a separate row.
Static Normalize & Format shows all three expressions. Static Compile places CSS to the
right of the props when the viewport is at least 720 pixels wide and stacks them on smaller screens.
