# Stillwind website

Stillwind compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when
AI agents write much of it.

This package contains Stillwind's private Astro website, which presents features
through compiler-generated examples and interactive demonstrations.

See [Development](DEVELOPMENT.md) for local tasks, presentation contracts, and assets.
