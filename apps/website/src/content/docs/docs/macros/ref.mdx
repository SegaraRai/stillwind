title: style.ref() and ref methods
description: Name an element with a ref, and style other elements from its state, size, or anchor position.

---

`style.ref(label?)` creates a ref: a name for an element that other styles can
refer to. Attach the ref to an element with `style(ref)`. Then use its methods to
style other elements from that element's state, size, or position.

## Example

<CompiledExample>

```tsx
import { style } from "stillwind/react";
const card = style.ref("card");
export const container = style(card, card.asContainer("inline-size"));
export const child = style({
  [card("hover")]: "text-blue-600",
  [card.at("width >= 40rem")]: "grid-cols-2",
});
```

</CompiledExample>

## Declare a ref

Write `style.ref()` as the initial value of a variable: `const card = style.ref("card")`.
The optional label must be a string literal. It appears in generated names and
helps you read them.

Each `style.ref()` call in the source creates one name. Rendering a component
many times does not create new names, and two refs with the same label stay
separate. You can export a ref, import it, and pass it as an argument.

## Methods

| Method                      | Where to write it           | Effect                                                              |
| --------------------------- | --------------------------- | ------------------------------------------------------------------- |
| `style(card)`               | A `style()` argument        | Attaches the ref to the element                                     |
| `card()`                    | A computed key in `style()` | Matches inside the ref element                                      |
| `card("hover")`             | A computed key in `style()` | Matches inside the ref element while it matches the variants        |
| `trigger("hover").in(card)` | A computed key in `style()` | Matches while `trigger` is hovered, inside a shared `card` ancestor |
| `card.at(query?)`           | A computed key in `style()` | Matches a container query on the ref element                        |
| `card.asContainer(type?)`   | A `style()` argument        | Makes the ref element a named container                             |
| `trigger.asAnchor(scope?)`  | A `style()` argument        | Makes the ref element a named anchor                                |
| `trigger.positionAnchor()`  | A `style()` argument        | Positions the styled element against the anchor                     |

Write each method call directly in `style()`. You cannot store the result of a
method call in a variable and use it later.

## Conditions on another element

`card("hover:active")` matches while the ref element matches every variant in the
string. The final colon is optional. A tagged template, such as ``card`hover` ``,
works the same way. You can also write the condition inside a utility template.

Without `.in()`, the ref element must be an ancestor of the styled element.

`trigger("hover").in(card)` matches when an element with the `card` ref contains
both the `trigger` element and the styled element. Use it for siblings. The
`card` element itself cannot be the styled element. Its operand is a ref or a
ref call without `.in()` and `.at()`. A condition on that operand, such as
`.in(card("focus-within"))`, tests the `card` element.

## Container queries

`card.asContainer(type?)` sets `container-name` on the ref element. The type is
a string literal: `normal`, `size`, `inline-size`, `scroll-state`, a supported
combination of these, or a CSS-wide keyword. Without a type, Stillwind does not
set `container-type`.

`card.at("width >= 40rem")` creates a container query for that name. Write the
query without its outer parentheses. `card.at()` with no query matches any
container with the name.

Pass `card` and `card.asContainer()` in the same `style()` call. The container
applies only to an element that has the ref, and
[missing-ref-attachment](/docs/lints/missing-ref-attachment/) reports a call
without it.

## Anchor positioning

`trigger.asAnchor(scope?)` sets `anchor-name` on the ref element. The optional
scope also sets `anchor-scope`. It accepts `"all"`, `"none"`, or an array of refs
written in the call. An array includes the `trigger` ref only when you list it.

`trigger.positionAnchor()` sets `position-anchor` on the styled element. That
element does not need the `trigger` ref, but the anchor element does.

To limit where an anchor name is visible, see
[style.anchorScope()](/docs/macros/anchor-scope/).

## Generated code

When the compiler knows which ref a call uses, the ref becomes plain class names
and selectors, and the ref variable can become `undefined` in JavaScript. When a
call chooses among several refs at runtime, the generated code keeps the fields
that the choice needs. The production build reads those fields directly, and the
development build checks them. Neither build watches the DOM.

See [Element relationships](/docs/guides/element-relationships/) for task-based
examples.
