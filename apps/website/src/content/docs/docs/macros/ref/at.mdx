---
title: ref.at()
description: Style an element with a container query on the element that has a ref.
slug: docs/macros/ref/at
---

`card.at(query?)` creates
[a container query](https://developer.mozilla.org/docs/Web/CSS/Guides/Containment/Container_queries)
on the container that the `card` ref names. Make that element a container with
[`card.asContainer()`](/docs/macros/ref/as-container).

## Example

<CompiledExample>

```tsx
import { style } from "stillwind/react";

const card = style.ref("card");
export const container = style(card, card.asContainer("inline-size"));
export const child = style({ [card.at("width >= 40rem")]: "grid-cols-2" });
```

</CompiledExample>

## Inputs

| Form                         | Generated condition                                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `card.at("width >= 40rem")`  | [`@container <name> (width >= 40rem)`](https://developer.mozilla.org/docs/Web/CSS/Reference/At-rules/@container) |
| ``card.at`width >= 40rem` `` | The same as the string form                                                                                      |
| `card.at()` or `card.at("")` | `@container <name>`                                                                                              |

Write the query as a string literal or a tagged template without interpolations.
Leave out the outer parentheses.

## Behavior

Without a query, the condition matches whenever the styled element is inside a
container with the name.

Write the call directly as a computed key in [`style()`](/docs/macros/style).
To use it in several places, store it with [`style.when()`](/docs/macros/when).

See [Element relationships](/docs/guides/element-relationships#react-to-a-containers-size)
for a task-based example.
