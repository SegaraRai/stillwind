title: "SW33001: Original map on an internal source"

<CompilerError code="SW33001" category="host" />

This error occurs when an integration registers an internal, generated buffer
with a source map entry for an original document. Only original documents may
have such entries. The message names the operation.

## Reported

```text
An internal generated buffer is registered with an original-document source map entry.
```

## Fixed

```text
The internal buffer is registered without an original-document source map entry.
```

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it.
- In your own integration, register original documents and generated buffers
  through separate paths.
