<CompilerError code="SW34003" category="host" />

This error occurs when an integration asks for the code edits of a module whose
compilation failed. A failed compilation has no complete result to turn into
edits.

## Reported

```text
Compilation fails, and the integration still asks for its code edits.
```

## Fixed

```text
Compilation succeeds, and the integration asks for the edits of that same revision.
```

## How to fix

- With an official integration, fix the error that the compilation reported
  first. If only this error appears, report it.
- In your own integration, handle compiler errors before you ask for edits. If
  the editor keeps an older successful result, keep its revision separate from
  the failed one.
