<CompilerError code="SW31010" category="host" />

This error occurs when the compiler must replace text in a component, but no
single editable region from the converter contains the whole replacement. Two
neighboring regions are not enough.

## Reported

```text
A replacement starts inside one editable region and ends inside the next one.
```

## Fixed

```text
The whole replacement lies inside one editable region.
```

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own converter, choose region boundaries that cover whole expressions.
