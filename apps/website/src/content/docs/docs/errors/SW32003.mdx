<CompilerError code="SW32003" category="host" />

This error occurs when an integration answers a request that the stylesheet
loader is not waiting for. The request ID is unknown, or the request already has
an answer.

## Reported

```text
Pending requests: 1, 2
Answer for request: 99
```

## Fixed

```text
Each answer names one pending request, and each request gets one answer.
```

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it.
- In your own integration, keep the request state for each loader, and do not
  pass late answers from an earlier load to a new one.
