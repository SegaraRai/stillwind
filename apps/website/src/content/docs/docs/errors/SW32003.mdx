---
title: "SW32003: Unknown or duplicate CSS request"
description: An answer to the stylesheet loader names a request that is not pending.
slug: docs/errors/SW32003
---

This error occurs when an integration answers a request that the stylesheet
loader is not waiting for. The request ID is unknown, or the request already has
an answer.

## Reported

<DiagnosticExample code="SW32003">

```ts
import { NativeDesignSystemLoader } from "@stillwind/native";

const loader = new NativeDesignSystemLoader();
loader.provide(0, "root.css", '@import "./tokens.css";');
loader.provide(99, "tokens.css", "@theme { --color-brand: red; }");
```

</DiagnosticExample>

## Fixed

```ts
import { NativeDesignSystemLoader } from "@stillwind/native";

const loader = new NativeDesignSystemLoader();
const step = loader.provide(0, "root.css", '@import "./tokens.css";');
if (step.kind === "needFile") {
  for (const request of step.requests) {
    loader.provide(request.id, "tokens.css", "@theme { --color-brand: red; }");
  }
}
```

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it.
- In your own integration, keep the request state for each loader, and do not
  pass late answers from an earlier load to a new one.
