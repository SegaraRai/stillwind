---
title: "SW01002: Invalid property prefix"
description: The prefix or tailwindPrefix setting does not start with -- and end with -.
slug: docs/errors/SW01002
---

This error occurs when `prefix` or `tailwindPrefix` is not a valid prefix for
custom properties. A prefix must start with `--`, end with `-`, and contain no
whitespace. The message names the setting.

## Reported

<DiagnosticExample code="SW01002">

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "sw",
    },
  ],
});
```

</DiagnosticExample>

## Fixed

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "--sw-",
    },
  ],
});
```

## How to fix

- Add `--` at the start and `-` at the end, as in the example.
- Use the same value in client and server builds that share styles.
- Keep `prefix` and `tailwindPrefix` different. See [SW01003](/docs/errors/SW01003).
