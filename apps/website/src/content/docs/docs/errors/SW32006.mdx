<CompilerError code="SW32006" category="host" />

This error occurs when the stylesheet loader needs another request ID, but has
used all the IDs that it can represent. A normal import graph never reaches this
limit, so the graph is probably growing without end.

## Reported

```text
An import graph keeps requesting new stylesheets until the loader has no IDs left.
```

## Fixed

```text
The import graph requests a finite set of stylesheets.
```

## How to fix

- Check your stylesheets and plugins for imports that generate new paths
  repeatedly.
- With an official integration, report the error with the number of stylesheets
  in the graph.
- In your own integration, do not reuse request IDs that are still pending.
