---
title: "SW10001: JavaScript parse error"
description: The JavaScript or TypeScript of a file has a syntax error.
slug: docs/errors/SW10001
---

This error occurs when the compiler cannot parse the JavaScript or TypeScript of
a file. The message shows the location and the explanation from the parser.

## Reported

<DiagnosticExample code="SW10001">

```tsx
export const props = style("p-4";
```

</DiagnosticExample>

## Fixed

```tsx
export const props = style("p-4");
```

## How to fix

- Fix the syntax at the location in the message, as in the example.
- If the file parses in your editor, check that the integration treats it as the
  right language, such as TypeScript with JSX for a `.tsx` file.

Errors in code that a Vue, Svelte, or Astro converter generated are reported as
[SW31004](/docs/errors/SW31004) instead.
