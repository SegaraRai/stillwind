<CompilerError code="SW32001" category="host" />

A single-buffer loading API encountered imports that require host resolution.
Its input does not include a resolver capable of answering those requests.

## Invalid loading choice

```text
A single-buffer API receives @import "./tokens.css" and cannot resolve that file.
```

## Valid loading choice

```text
The host uses DesignSystemLoader and answers its ordered import requests.
```

Use the supported host's CSS graph loader. An embedding must resolve each
requested import with its source or an explicit unresolved answer where allowed;
the configured root cannot be unresolved.
