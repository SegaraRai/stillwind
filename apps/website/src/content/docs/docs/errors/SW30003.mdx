---
title: "SW30003: Incompatible symbolic fact kinds"
description: The type information describes a value as the wrong kind, such as a keyframes definition as a ref.
slug: docs/errors/SW30003
---

This error occurs when the type information describes a value as a different kind
of definition than the code uses it as. For example, it encodes a keyframes
definition as a ref. The compiler cannot read the fields of one kind as another.

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it with the declaration and the code that uses it.
- In your own integration, fix the conversion from TypeScript types to the
  compiler's facts, and collect the facts again.
