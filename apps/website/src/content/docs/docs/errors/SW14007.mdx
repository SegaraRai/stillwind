---
title: "SW14007: Malformed theme reference"
description: A --theme() call in your stylesheet has invalid syntax.
slug: docs/errors/SW14007
---

This error occurs when a `--theme()` call in your stylesheet has invalid syntax,
such as no token name.

## Reported

<DiagnosticExample code="SW14007">

```css
.card {
  color: --theme();
}
```

</DiagnosticExample>

## Fixed

```css
.card {
  color: --theme(--color-blue-500);
}
```

## How to fix

Write the full name of a theme token, with an optional fallback after a comma,
such as `--theme(--color-brand, blue)`.

A valid reference to a token that the theme does not define is reported by
[invalid-theme-reference](/docs/lints/invalid-theme-reference/) instead.
