<CompilerError code="SW33003" category="host" />

This error occurs when a source range that belongs to one file is applied to
another file. The offsets may be valid numbers in both files, but they point to
different text. The message shows the expected and the actual file IDs.

## Reported

```text
A range from file A is applied to file B.
```

## Fixed

```text
The range from file A is applied to file A.
```

## How to fix

- With an official integration, report the error with the files and the action
  that caused it.
- In your own integration, keep the file ID together with each range through
  caches and conversions.
