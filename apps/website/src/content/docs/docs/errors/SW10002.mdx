---
title: "SW10002: Invalid component syntax"
description: A Vue, Svelte, or Astro component has a syntax error.
slug: docs/errors/SW10002
---

This error occurs when the parser of the framework cannot read a Vue, Svelte, or
Astro component. The message shows the location and the explanation from that
parser.

## Reported

<DiagnosticExample code="SW10002">

```html
<template><button></template>
```

</DiagnosticExample>

## Fixed

```html
<template><button></button></template>
```

## How to fix

Fix the syntax at the location in the message, as in the example, where the
`<button>` element was not closed.

If the component is valid but its converted script is not, the error is
[SW31004](/docs/errors/SW31004) instead.
