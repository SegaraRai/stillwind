<CompilerError code="SW13003" category="authoring" />

A scanner operation expected one balanced block and could not consume the
construct at the reported UTF-8 byte offset. An unmatched or incorrect delimiter
can violate that operation's input contract.

## Rejected block contract

```text
The selected block begins at an opening delimiter but closes with a different delimiter.
```

## Accepted block contract

```text
The opening and closing delimiters match, and the complete block lies in the same buffer.
```

Correct the retained source around that offset. If a host selected the wrong
buffer slice, reproduce the operation and repair the slice rather than editing unrelated CSS.
