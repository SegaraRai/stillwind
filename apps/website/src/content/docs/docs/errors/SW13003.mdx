---
title: "SW13003: Invalid CSS block"
description: The compiler cannot read a balanced CSS block.
slug: docs/errors/SW13003
---

This error occurs when the compiler cannot consume a CSS block while it reads
the stylesheet, imports, or plugin options. The message gives the position as a
byte offset.

## How to fix

Check the delimiters around that position and any strings or comments inside the
block. If the stylesheet is valid, report the source and the Stillwind version.

An unclosed block normally produces [SW13002](/docs/errors/SW13002). Other CSS
syntax errors can produce [SW13001](/docs/errors/SW13001).
