<CompilerError code="SW13003" category="authoring" />

This error occurs when the compiler expects one balanced block, but the block
closes with a different delimiter than it opened with. The message gives the
position as a byte offset.

## Reported

```css
.card {
  color: rgb(0 0 255];
}
```

## Fixed

```css
.card {
  color: rgb(0 0 255);
}
```

## How to fix

Match each opening delimiter with its closing one. In the example, `(` was closed
with `]`.

If you write your own integration and the stylesheet is valid, check that the
integration passed the whole block to the compiler.
