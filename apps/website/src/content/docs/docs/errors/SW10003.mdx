<CompilerError code="SW10003" category="authoring" />

This error occurs when one file imports Stillwind from the entrypoints of more
than one framework. The compiler produces props and runtime helpers for one
framework in each file.

## Reported

```ts
import { style as reactStyle } from "stillwind/react";
import { style as vueStyle } from "stillwind/vue";
```

## Fixed

```ts
import { style } from "stillwind/react";
```

## How to fix

Put the components of each framework in their own files, and import from one
entrypoint in each file. In the example, the React file keeps `stillwind/react`,
and the Vue code moves to a file that imports `stillwind/vue`.

A project can use several frameworks. The limit applies to each file.
