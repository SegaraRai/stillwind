description: A requested UTF-16 offset is outside the source or inside a character.

<CompilerError code="SW31006" category="host" />

This error occurs when an integration or a tool asks for a UTF-16 offset that is
not a valid position in the source, such as an offset past the end. UTF-16
offsets count code units, not bytes.

## Reported

```text
Source length: 20 UTF-16 code units
Requested offset: 100
```

## Fixed

```text
The requested offset is between 0 and 20.
```

## How to fix

- With an official integration, report the error with the file and the action
  that caused it.
- In your own integration, use offsets from the same revision of the source, and
  convert explicitly between byte offsets and UTF-16 offsets.
