---
title: "SW01003: Conflicting property prefixes"
description: The prefix setting has the same value as tailwindPrefix or themePrefix.
slug: docs/errors/SW01003
---

This error occurs when `prefix` has the same value as `tailwindPrefix` or
`themePrefix` after the defaults apply. Stillwind's own custom properties would
then share names with the Tailwind-compatible properties or the theme variables.
`themePrefix` may have the same value as `tailwindPrefix`.

## Reported

<DiagnosticExample code="SW01003">

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "--tw-",
    },
  ],
});
```

</DiagnosticExample>

## Fixed

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "--app-",
    },
  ],
});
```

## How to fix

- Give `prefix` a different value. In the example, `prefix` used the
  default value of `tailwindPrefix`, `--tw-`.
- Check the values that the integration options add on top of the file.
