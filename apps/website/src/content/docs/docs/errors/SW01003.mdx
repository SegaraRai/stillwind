---
title: "SW01003: Conflicting property prefixes"
description: The prefix and tailwindPrefix settings have the same value.
slug: docs/errors/SW01003
---

This error occurs when `prefix` and `tailwindPrefix` have the same value after
the defaults apply. Stillwind's own custom properties and the Tailwind-compatible
ones would then share names.

## Reported

<DiagnosticExample code="SW01003">

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "--tw-",
    },
  ],
});
```

</DiagnosticExample>

## Fixed

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.tsx"],
      prefix: "--app-",
    },
  ],
});
```

## How to fix

- Give the two settings different values. In the example, `prefix` used the
  default value of `tailwindPrefix`, `--tw-`.
- Check the values that the integration options add on top of the file.
