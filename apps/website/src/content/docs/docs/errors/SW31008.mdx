---
title: "SW31008: Invalid UTF-8 offset"
description: Keep byte offsets within the source and on UTF-8 code-point boundaries.
slug: docs/errors/SW31008
---

<CompilerError code="SW31008" category="host" />

The requested UTF-8 byte offset cannot be converted to a source position.
An offset inside a multibyte character is not a valid code-point boundary.

## Invalid request

```text
Buffer: é
UTF-8 byte offset: 1
```

## Valid request

```text
For that buffer, byte offsets 0 and 2 identify its beginning and end.
```

Use UTF-8 byte coordinates for byte APIs. Convert UTF-16 editor positions with
the source service instead of treating a character count as a byte count.
