<CompilerError code="SW34002" category="host" />

The source requests an explicit module CSS import, but the host supplied no
virtual module target for it. A compiled CSS value still needs a delivery mechanism
owned by the integration.

## Invalid integration contract

```text
The source imports stillwind/module-css without a host-allocated virtual target.
```

## Valid integration contract

```text
The adapter supplies the virtual target used to replace that explicit import.
```

Confirm that the build-tool integration owns the source transformation. An
embedding must allocate the target before rendering replacement imports.
