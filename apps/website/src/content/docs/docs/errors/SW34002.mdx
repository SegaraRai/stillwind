<CompilerError code="SW34002" category="host" />

This error occurs when a file imports `stillwind/module-css`, but the integration
did not create the virtual module that replaces the import. The compiled CSS has
nowhere to go.

## Reported

```text
A file imports stillwind/module-css, and the build runs without a Stillwind integration.
```

## Fixed

```text
The build uses a Stillwind integration, which creates the virtual module.
```

## How to fix

- Check that the build tool runs the Stillwind integration on this file. See
  [Framework integrations](/docs/frameworks/).
- In your own integration, create the virtual module before you render the
  replacement imports.
