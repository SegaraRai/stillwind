---
title: "SW31004: Invalid converter output syntax"
description: The script that a converter generated from a valid component has a syntax error.
slug: docs/errors/SW31004
---

This error occurs when a Vue, Svelte, or Astro component is valid, but the script
that the converter generates from it cannot be parsed. The message contains the
explanation from the parser.

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own converter, fix the generated code, or select the right language
  for the parser.

A syntax error in the component itself is reported as
[SW10002](/docs/errors/SW10002/) instead.
