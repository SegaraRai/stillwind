---
title: "SW32004: Conflicting CSS source"
description: One stylesheet name received two different contents during one load.
slug: docs/errors/SW32004
---

This error occurs when an integration gives the stylesheet loader two different
documents or contents for the same file name during one load. This can happen
when a file changes while it is loading.

## How to fix

- With an official integration, save the file and build again. If the error
  remains, report it.
- In your own integration, read the files from one snapshot for each load, and
  start a new load when a file changes.
