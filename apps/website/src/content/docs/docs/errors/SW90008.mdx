<CompilerError code="SW90008" category="internal" />

The compiler applied coordinates that it produced, and the source rejected
them. The diagnostic carries the operation context and the source failure detail.

## Violated invariant

```text
A compiler-produced span or offset fails the checked source-coordinate contract.
```

## Required invariant

```text
Compiler-produced coordinates satisfy the source's bounds, identity, and boundary checks.
```

Report the original source, operation context, and failure detail. Invalid
coordinates supplied by a host use the `SW33...` family instead; the distinction
identifies which side must repair the coordinate construction.
