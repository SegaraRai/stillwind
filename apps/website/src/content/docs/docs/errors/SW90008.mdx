<CompilerError code="SW90008" category="internal" />

This error occurs when the compiler produces a source position that is outside the file or inside a character. When an integration passes an invalid position instead, the error is one of the `SW33xxx` codes.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The source file
- The operation and the detail from the message
- The version of the Stillwind packages
