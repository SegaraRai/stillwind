---
title: "SW14002: Missing support slot"
description: Your stylesheet has no place for CSS that a feature needs, such as keyframes.
slug: docs/errors/SW14002
---

<CompilerError code="SW14002" category="authoring" />

This error occurs when the compiler generates supporting CSS, such as the
`@keyframes` of an animation, but your stylesheet has no slot for it. The message
names the missing slot.

## Reported

```css
@import "stillwind/utilities.css" layer(utilities);
@import "stillwind/builtins.css";
```

## Fixed

```css
@import "stillwind/utilities.css" layer(utilities);
@import "stillwind/builtins.css";
@stillwind-slot keyframes;
```

## How to fix

- Add the slot that the message names, as in the example. `stillwind/theme.css`
  contains the `theme` and `keyframes` slots.
- If you do not need a custom selection, import `stillwind` instead.
