<CompilerError code="SW32002" category="host" />

This error occurs when the first answer that an integration gives the stylesheet
loader does not contain exactly one stylesheet. The first answer is the root
stylesheet. The loader then asks for the imports that the root contains.

## Reported

```text
First answer: root.css and tokens.css
```

## Fixed

```text
First answer: root.css
Later answers: tokens.css, when the loader asks for it
```

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it.
- In your own integration, give only the root stylesheet first, and answer the
  later requests with the IDs that the loader returns.
