---
title: "SW15001: CSS offset exceeds source coordinates"
description: A stylesheet is too large for the compiler's source positions.
slug: docs/errors/SW15001
---

This error occurs when a stylesheet is so large that a position in it does not
fit in the compiler's 32-bit source positions, which allow about 4 GB. Such a
stylesheet is almost always generated by mistake.

## How to fix

- Find the tool or plugin that generates the stylesheet, and limit its output.
- Split the stylesheet into several files.

If the stylesheet has a normal size, report the error as a bug with the input
sizes.
