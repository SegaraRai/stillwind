<CompilerError code="SW31003" category="host" />

This error occurs when the converted script and the original component contain
different text at a location that the map links. The compiler would edit the
wrong text, so it stops.

## Reported

```text
Generated script: "p-4"
Original component at the mapped range: "p-2"
```

## Fixed

```text
Both texts contain "p-4" at the mapped range.
```

## How to fix

- With an official integration, save the file and build again, in case the
  editor passed an old buffer. If the error remains, report it with the
  component.
- In your own converter, check rewrites and escaping of the mapped text, and do
  not reuse a map for a changed buffer.
