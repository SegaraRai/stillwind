<CompilerError code="SW34001" category="host" />

This error occurs when the compiled code needs a runtime or stylesheet import,
but the compiler cannot find the `stillwind` import that it replaces with those
imports. In a component with several script blocks, the import must be in the
same block as the code that uses it.

## Reported

```text
A converter moves or removes the import from "stillwind/vue" before compilation.
```

## Fixed

```text
The converter keeps the import, and records which script block it belongs to.
```

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own converter, keep the Stillwind import in place, and record its
  script block correctly.
