title: "SW32007: CSS source IDs exhausted"
description: The stylesheet loader ran out of IDs for different stylesheet files.

<CompilerError code="SW32007" category="host" />

This error occurs when the stylesheet loader needs an ID for another stylesheet
file, but has used all the IDs that it can represent. Each distinct file needs an
ID, so the graph contains far more files than a normal project, or the same file
keeps getting new identities.

## Reported

```text
The resolver returns a new identity for the same file on every request.
```

## Fixed

```text
The resolver returns one identity for each file.
```

## How to fix

- Check your stylesheets and plugins for imports that generate new paths
  repeatedly.
- With an official integration, report the error with the number of stylesheets
  and how the resolver names them.
- In your own integration, give each file one stable identity, and create a new
  loader when you start over.
