---
title: "SW32007: CSS source IDs exhausted"
description: Keep the loaded source set within the source-file allocator's range.
slug: docs/errors/SW32007
---

<CompilerError code="SW32007" category="host" />

The loader cannot allocate another source-file identity. Request IDs and source
identities have different roles; reducing duplicate requests alone may not reduce
the number of distinct source files.

## Invalid state

```text
The graph needs more source identities than the allocator can represent.
```

## Valid state

```text
Every source in the loaded graph has a representable source-file identity.
```

Inspect unexpected graph expansion or identity churn. Reduce the source set and
recreate the loader/session when appropriate; retain counts and resolver identities in a report.
