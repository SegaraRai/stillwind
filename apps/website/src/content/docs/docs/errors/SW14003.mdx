<CompilerError code="SW14003" category="authoring" />

An authored `@stillwind-require-properties` directive contains malformed names
or syntax. The byte offset is relative to the CSS body that contains the directive.

## Rejected requirement form

```text
The requirement lists an incomplete custom-property name or malformed arguments.
```

## Supported requirement form

```css
@stillwind-require-properties --tw-rotate-x;
```

Use the complete registered name. A syntactically valid requirement for an
unregistered property is a different failure, [SW14005](/docs/errors/SW14005/).
Requirements inside a matched utility use [SW14004](/docs/errors/SW14004/).
