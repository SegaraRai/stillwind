<CompilerError code="SW14003" category="authoring" />

This error occurs when an `@stillwind-require-properties` directive in your
stylesheet has invalid syntax, such as an incomplete custom property name. The
directive lists the registered custom properties that a utility needs. The
message gives the position within the rule that contains it.

## Reported

```css
@utility spin-x {
  @stillwind-require-properties tw-rotate-x;
  transform: var(--tw-rotate-x);
}
```

## Fixed

```css
@utility spin-x {
  @stillwind-require-properties --tw-rotate-x;
  transform: var(--tw-rotate-x);
}
```

## How to fix

Write each name in full, including the leading `--`, as in the example.

A valid name that no registration provides is reported as
[SW14005](/docs/errors/SW14005/). An invalid directive inside a utility from a
plugin is reported as [SW14004](/docs/errors/SW14004/).
