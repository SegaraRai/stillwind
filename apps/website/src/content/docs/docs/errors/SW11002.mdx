---
title: "SW11002: CSS module ordering cycle"
description: Two modules each build styles on a base from the other module.
slug: docs/errors/SW11002
---

This error occurs when two modules each build a style on a base from the other
module. The CSS of each module must come after the CSS of the modules that it
builds on, so the two modules have no valid order, even when the individual
styles do not form a cycle.

## Reported

<DiagnosticExample code="SW11002">

```ts title="entry.ts"
import { style } from "stillwind/react";
import { middle } from "./middle";

export const base = style("p-4");
export const derived = style(middle, "rounded-md");
```

```ts title="middle.ts"
import { style } from "stillwind/react";
import { base } from "./entry";

export const middle = style(base, "text-blue-600");
```

</DiagnosticExample>

## Fixed

```ts title="base.ts"
import { style } from "stillwind/react";

export const base = style("p-4");
```

```ts title="entry.ts"
import { style } from "stillwind/react";
import { middle } from "./middle";

export { base } from "./base";
export const derived = style(middle, "rounded-md");
```

```ts title="middle.ts"
import { style } from "stillwind/react";
import { base } from "./base";

export const middle = style(base, "text-blue-600");
```

## How to fix

- Move the shared bases into a module that both modules import, as in the
  example.
- Or put the styles that depend on each other in the same module.

Changing the order of the imports does not fix it.
