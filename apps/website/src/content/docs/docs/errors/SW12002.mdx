---
title: "SW12002: Declaration identities unavailable"
description: The compiler cannot tell which refs or animations a value can hold.
slug: docs/errors/SW12002
---

This error occurs when the compiler cannot tell which refs, keyframes, or view
transitions a value can hold. When a ref is chosen at runtime, the compiler must
generate CSS for every ref that it can be. A type annotation that widens the type
hides that list.

## Reported

<DiagnosticExample code="SW12002">

```ts
const card = style.ref("card");
const current: ReturnType<typeof style.ref> = card;
style({ [current("hover")]: "underline" });
```

</DiagnosticExample>

## Fixed

```ts
const card = style.ref("card");
const current = card;
style({ [current("hover")]: "underline" });
```

## How to fix

- Remove the type annotation, and keep the type that TypeScript infers, as in the
  example.
- When a value can hold several refs, use an explicit union of their types, such
  as `typeof card | typeof panel`, or a generic parameter.
- Make the source modules of the definitions reachable through imports.

If the integration did not provide type information at all, the error is
[SW30001](/docs/errors/SW30001/) instead.
