<CompilerError code="SW01007" category="configuration" />

This error occurs when a custom `naming` function fails while it generates a
name. The message shows which kind of name it was generating and the error from
the function. The compiler does not invent a name in its place.

## Reported

```text
The naming function for utility classes throws an error for some requests.
```

## Fixed

```text
The naming function returns a valid name for every request, or undefined to keep
the default name.
```

## How to fix

- Reproduce the request from the message, and fix the function so that it returns
  a name or `undefined`.
- Keep the function pure: the same request must always produce the same name.
- Change `namingRevision` whenever you change the function.
