---
title: "SW90001: Invalid generated CSS block"
description: The compiler generated CSS that is not made of complete rules.
slug: docs/errors/SW90001
---

This error occurs when the CSS that the compiler generates for a style cannot be split into complete rules. The message gives the position in the generated CSS. Your code does not need to change; the compiler made a mistake.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The `style()` call or utility that causes the error
- Your stylesheet, or the parts that the utility uses
- The version of the Stillwind packages
