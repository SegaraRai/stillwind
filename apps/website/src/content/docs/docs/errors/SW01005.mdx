<CompilerError code="SW01005" category="configuration" />

This error occurs when two different styles, refs, or animations would receive
the same generated name. The usual cause is a custom `naming` function that
returns the same name for different requests. A very short `hashLength` can also
cause it.

## Reported

```text
Request for style A -> "button"
Request for style B -> "button"
```

## Fixed

```text
Request for style A -> "button_a1b2c"
Request for style B -> "button_d3e4f"
```

## How to fix

- Make the `naming` function keep the hash from the request in the name, as in
  the example, or return `undefined` to use the default name.
- If you use the default names, raise `hashLength`.
- Change `namingRevision` whenever you change a `naming` function.
