<CompilerError code="SW90007" category="internal" />

This error occurs when the compiler plans two edits that change the same text. The message shows the positions of both edits. Applying the edits in another order does not help.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The code at the positions in the message
- How the styles there are nested or used as bases
- The version of the Stillwind packages
