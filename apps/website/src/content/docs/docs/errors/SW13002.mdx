<CompilerError code="SW13002" category="authoring" />

This error occurs when a block in your stylesheet opens but does not close before
the end of the file. The message gives the position as a byte offset from the
start of the parsed text, counting from zero.

## Reported

```css
.card { color: blue;
```

## Fixed

```css
.card {
  color: blue;
}
```

## How to fix

- Add the missing `}`, `)`, or `]`.
- Also check for an unclosed string or comment before that position. An unclosed
  string can make the rest of the file look like one block.
