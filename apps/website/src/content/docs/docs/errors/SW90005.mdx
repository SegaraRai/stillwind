---
title: "SW90005: Macro anchor removal edit missing"
description: The compiler chose a Stillwind import to replace, but did not plan its replacement.
slug: docs/errors/SW90005
---

This error occurs when the compiler chooses the `stillwind` import where it adds runtime imports, but does not plan the edit that replaces it. If the integration provided no usable import at all, the error is [SW34001](/docs/errors/SW34001) instead.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The file and its `stillwind` import
- The version of the Stillwind packages
