<CompilerError code="SW31011" category="host" />

This error occurs when the converter records a different quote character for an
attribute than the component uses. The compiler escapes its replacement for the
recorded quote, so a wrong record could break the attribute.

## Reported

```text
Attribute in the component: double quotes
Recorded quote: single quote
```

## Fixed

```text
The recorded quote matches the quotes of the attribute.
```

## How to fix

- With an official integration, save the file and build again, in case the
  editor passed an old buffer. If the error remains, report it with the
  component.
- In your own converter, record the quote from the same revision of the source.
