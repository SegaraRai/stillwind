A compiler error stops the compilation of a module. Unlike a lint finding, you
cannot turn it off or suppress it with a comment. Each error page explains what
causes the error and how to fix it.

The first digits of a code tell you what to do next:

| Codes             | What to do                                           |
| ----------------- | ---------------------------------------------------- |
| SW01xxx           | Fix `stillwind.config.ts` or the integration options |
| SW10xxx – SW15xxx | Fix your components, `style()` calls, or stylesheet  |
| SW30xxx – SW34xxx | Check your integration, or report a bug              |
| SW90xxx           | Report a bug                                         |

## Check your integration

These errors come from the connection between the compiler and the build tool
or the editor. With an official integration, update the Stillwind packages
first. If the error remains, report it as a bug. If you write your own
integration, the error page explains which input to fix.

## Report a bug

These errors mean that the compiler produced an inconsistent result. Please
[open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and, if possible, the source that causes it.
