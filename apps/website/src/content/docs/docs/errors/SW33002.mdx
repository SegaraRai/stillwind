---
title: "SW33002: Invalid source byte range"
description: A requested byte range ends before it starts, or is otherwise unusable.
slug: docs/errors/SW33002
---

This error occurs when an integration or a tool passes a byte range that the
source operation cannot use, such as a range that ends before it starts. The
message shows the start, the end, and the operation.

## How to fix

- With an official integration, report the error with the file and the action
  that caused it.
- In your own integration, pass half-open UTF-8 byte ranges with the start before
  the end, and compute them again after each edit.
