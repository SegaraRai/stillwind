---
title: "SW12001: Incompatible declaration assignment"
description: A variable that holds one ref or animation is assigned a different one.
slug: docs/errors/SW12001
---

This error occurs when a variable that holds one ref, keyframes, or view
transition definition is later assigned a different one. The compiler tracks
which definitions a variable can hold, and the assignment breaks that record.
The message includes the explanation from TypeScript.

## Reported

<DiagnosticExample code="SW12001">

```ts
let current = style.ref("card");
current = style.ref("panel");
style({ [current("hover")]: "underline" });
```

</DiagnosticExample>

## Fixed

```ts
const card = style.ref("card");
const panel = style.ref("panel");
let current: typeof card | typeof panel = card;
current = panel;
style({ [current("hover")]: "underline" });
```

## How to fix

- Declare each definition in its own `const`, and give the variable an explicit
  union of their types, as in the example.
- In a function that accepts several definitions, use a generic parameter instead
  of a wider type.
- Keep the types that TypeScript infers when you pass definitions through
  exports.
