---
title: "SW33004: Invalid source span"
description: A source range lies outside its file or splits a multibyte character.
slug: docs/errors/SW33004
---

This error occurs when an integration or a tool passes a source range whose ends
lie outside the file, or inside a character of several bytes. The message names
the operation.

## How to fix

- With an official integration, report the error with the file and the action
  that caused it.
- In your own integration, build ranges from checked offsets of the same revision
  of the file.
