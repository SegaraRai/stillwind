---
title: "SW30004: Checker expression unavailable"
description: The integration cannot find the code that TypeScript needs to check for an expression.
slug: docs/errors/SW30004
---

This error occurs when the compiler needs type information for an expression, but
the integration cannot find that expression in the code that TypeScript checks.
This usually happens in Vue, Svelte, or Astro components, where a converter
produces the checked code. The message names the operation.

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own integration, keep the mapping between the original expressions and
  the checked code, including for unsaved editor buffers.
