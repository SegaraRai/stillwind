<CompilerError code="SW11001" category="authoring" />

This error occurs when styles use each other as a base, directly or through other
styles. The CSS of a base comes before the CSS of the styles built on it, so a
cycle has no valid order.

## Reported

```tsx
const first = style(second);
const second = style(first);
```

## Fixed

```tsx
const first = style("p-2");
const second = style(first, "p-4");
```

## How to fix

- Build in one direction only: decide which style is the base, as in the example.
- If both styles share utilities, move them into a third base that both use.

A cycle between whole modules is reported as [SW11002](/docs/errors/SW11002/)
instead.
