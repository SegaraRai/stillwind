---
title: "SW14005: Required property is unregistered"
description: Register the custom property named by a generated support requirement.
slug: docs/errors/SW14005
---

<CompilerError code="SW14005" category="authoring" />

A requirement names a custom property with no `@stillwind-property` registration
in the loaded design system. A declaration that merely assigns the property does
not supply that registration's support contract.

## Rejected registry contract

```text
A requirement names --custom-value; no registration provides --custom-value.
```

## Accepted registry contract

```text
The loaded graph registers --custom-value before rendering output that requires it.
```

Load the definition that owns the required support or correct the requirement's
name. Review custom utilities and plugin definitions when the standard entry already loads correctly.
