---
title: "SW14005: Required property is unregistered"
description: A utility requires a custom property that no @stillwind-property registers.
slug: docs/errors/SW14005
---

This error occurs when a utility requires a custom property, but no
`@stillwind-property` in the loaded stylesheets registers it. The registration
provides the initial value and other support CSS. Assigning the property in a
rule does not register it.

## Reported

<DiagnosticExample code="SW14005">

```css
@utility spin-x {
  @stillwind-require-properties --spin-angle;
  rotate: var(--spin-angle);
}
```

```tsx
style("spin-x");
```

</DiagnosticExample>

## Fixed

```css
@stillwind-property --spin-angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

@utility spin-x {
  @stillwind-require-properties --spin-angle;
  rotate: var(--spin-angle);
}
```

```tsx
style("spin-x");
```

## How to fix

- Register the property with `@stillwind-property`, as in the example.
- If the property comes from Stillwind or a plugin, check that the stylesheet
  imports the file that registers it, and check the spelling of the name.
