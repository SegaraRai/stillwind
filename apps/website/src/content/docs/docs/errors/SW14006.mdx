<CompilerError code="SW14006" category="authoring" />

This error occurs when a CSS value has a syntax error, such as an unclosed
function. The compiler reads values to find the custom properties that they use,
and it cannot tell which support CSS to include for a value that it cannot read.

## Reported

```css
@utility glow {
  box-shadow: 0 0 8px var(--glow-color;
}
```

## Fixed

```css
@utility glow {
  box-shadow: 0 0 8px var(--glow-color);
}
```

## How to fix

- Fix the value in your stylesheet or utility definition, as in the example.
- If the value comes from a plugin, report the definition and the plugin version
  to the plugin's maintainer.
