<CompilerError code="SW31005" category="host" />

A converter or checker projection could not prepare the required correspondence.
The diagnostic includes the projection adapter's explanation of that failure.

## Invalid preparation result

```text
Preparation fails before it can supply the required original/checker correspondence.
```

## Valid preparation result

```text
Preparation returns the supported document and correspondence required by its consumer.
```

Reproduce with compatible framework and integration versions. An embedding must
propagate preparation failure instead of compiling a partially prepared projection.
