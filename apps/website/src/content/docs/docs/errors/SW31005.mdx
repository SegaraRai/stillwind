---
title: "SW31005: Component projection preparation failed"
description: The converter for a Vue, Svelte, or Astro component failed before compilation.
slug: docs/errors/SW31005
---

This error occurs when the converter that prepares a Vue, Svelte, or Astro
component for compilation or type checking fails. The message contains the
explanation from the converter.

## How to fix

- With an official integration, check that the framework and Stillwind package
  versions are supported, and update them. If the error remains, report it with
  the component.
- In your own integration, report the converter failure instead of compiling a
  partly prepared component.
