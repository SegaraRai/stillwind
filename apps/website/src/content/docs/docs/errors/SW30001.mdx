<CompilerError code="SW30001" category="host" />

This error occurs when the compiler needs TypeScript type information to compile
a value, but the integration compiled the file without it. Examples are a ref
chosen by a condition, or an animation imported from another module. The message
names the kind of value.

## Reported

```text
The integration compiles a file that chooses a ref at runtime, without type information.
```

## Fixed

```text
The integration collects type information for the file, then compiles the same revision of the file.
```

## How to fix

- With an official integration, update the Stillwind packages. If the error
  remains, report it with the file that causes it.
- In your own integration, run the type queries before compilation, and pass
  their results with the same revision of the source.

Type information that exists but does not match the source is reported as
[SW30002](/docs/errors/SW30002/).
