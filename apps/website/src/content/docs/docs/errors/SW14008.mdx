---
title: "SW14008: Circular utility application"
description: A utility applies itself directly or through another utility.
slug: docs/errors/SW14008
---

This error occurs when an `@apply` dependency returns to a utility that is already
being expanded. The cycle can pass through several utilities.

## Reported

<DiagnosticExample code="SW14008">

```css
@utility card {
  @apply card;
}

.card {
  @apply card;
}
```

</DiagnosticExample>

## Fixed

```css
@utility card {
  display: block;
  padding: 1rem;
}

.card {
  @apply card;
}
```

## How to fix

Remove the `@apply` that closes the dependency cycle. A shared utility can contain
the common declarations, provided that it does not apply the utilities that use it.
