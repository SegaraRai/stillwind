---
title: "SW10005: Untransformed macro reference"
description: The style function is used as a value instead of being called.
slug: docs/errors/SW10005
---

This error occurs when the code uses `style` or another macro as a value, such as
by storing it in a variable or passing it to a function. The compiler replaces
macro calls at build time and removes the import, so the function does not exist
at runtime.

## Reported

<DiagnosticExample code="SW10005">

```tsx
import { style } from "stillwind/react";

const macro = style;
macro("p-4");
```

</DiagnosticExample>

## Fixed

```tsx
import { style as macro } from "stillwind/react";

const props = macro("p-4");
```

## How to fix

- Call `style()` directly, as in the example.
- To share a style, store and pass the result of `style()`, not the function.
