---
title: "SW31009: Unmapped macro binding read"
description: A use of style in a converted component has no mapping to the original component.
slug: docs/errors/SW31009
---

This error occurs when a use of `style` or another macro in the converted script
of a component has no mapping to the original component. The compiler removes the
macro import, so it must find every use first.

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own converter, map the import and every use together.

Renaming `style` in the component does not fix it.
