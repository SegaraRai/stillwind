<CompilerError code="SW31009" category="host" />

A macro binding has reads without verified projection correspondence. The compiler
cannot prove that it found every original reference before replacing the macro import.

## Invalid mapping contract

```text
The converter maps the macro declaration but omits one of its binding reads.
```

## Valid mapping contract

```text
Every macro read that must be transformed has verified correspondence in the original source.
```

Audit declaration and reference mappings together. Include the omitted read and
both buffers in a converter reproduction; renaming the original macro does not repair the map.
