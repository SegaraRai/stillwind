---
title: "SW31001: Invalid projection map"
description: The mapping between a component and its converted script is malformed.
slug: docs/errors/SW31001
---

This error occurs when the map that links a Vue, Svelte, or Astro component to its
converted script is malformed. For example, a range in the map extends past the
end of the text that it refers to. The message describes the problem.

## How to fix

- With an official integration, update the Stillwind packages and the framework
  packages. If the error remains, report it with the component.
- In your own converter, check each range against the exact texts that you pass
  to the compiler.

A valid map that cannot point to one original range is reported as
[SW31002](/docs/errors/SW31002/).
