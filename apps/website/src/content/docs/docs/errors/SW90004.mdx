<CompilerError code="SW90004" category="internal" />

This error occurs when the compiler's record of a `stillwind` import does not match the source, for example after an edit in the editor.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The import statement and the type of the file, such as `.tsx` or `.vue`
- The versions of the Stillwind and framework packages
- Whether the error appears only after an edit, and which edit
