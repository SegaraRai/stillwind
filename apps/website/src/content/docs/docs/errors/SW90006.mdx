<CompilerError code="SW90006" category="internal" />

A generated source transform contains invalid expression-mapping metadata.
The diagnostic identifies the original call span carrying that replacement.

## Violated invariant

```text
A retained expression occurrence has an invalid correspondence in the generated replacement.
```

## Required invariant

```text
Every retained occurrence has its own valid original/generated transform correspondence.
```

Report the original expression and its generated replacement. Preserve repeated
or conditional uses in a reduction when removing them makes the mapping failure disappear.
