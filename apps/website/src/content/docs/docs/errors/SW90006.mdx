<CompilerError code="SW90006" category="internal" />

This error occurs when an edit that the compiler generates links to the original expression incorrectly. The message names the `style()` call.

## How to report

[Open an issue](https://github.com/SegaraRai/stillwind/issues) with the error
message and:

- The `style()` call from the message
- Other uses of the same style in the file, because repeated or conditional uses can matter
- The version of the Stillwind packages
