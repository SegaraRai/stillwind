<CompilerError code="SW33005" category="host" />

This error occurs when an integration or a tool passes a byte offset that a
source operation cannot use, because it lies outside the file or inside a
character of several bytes. The message shows the offset and the operation.

## Reported

```text
Source: é
Requested byte offset for an edit: 1
```

## Fixed

```text
Requested byte offset for an edit: 0 or 2
```

## How to fix

- With an official integration, report the error with the file and the action
  that caused it.
- In your own integration, convert editor positions to byte offsets explicitly,
  and discard stored offsets after edits.

Errors from the APIs that convert positions are reported as
[SW31008](/docs/errors/SW31008/) instead.
