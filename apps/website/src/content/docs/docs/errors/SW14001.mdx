---
title: "SW14001: Missing utilities slot"
description: Your stylesheet does not place the generated utility CSS anywhere.
slug: docs/errors/SW14001
---

This error occurs when your stylesheet has no `@stillwind-slot utilities;`. The
slot marks where the compiler writes the CSS of the utilities that you use. The
default stylesheet contains it, so the error usually appears when a stylesheet
imports only some parts of Stillwind.

## Reported

<DiagnosticExample code="SW14001">

```css
@import "stillwind/theme.css" layer(theme);
@import "stillwind/builtins.css";
```

```tsx
style("p-4");
```

</DiagnosticExample>

## Fixed

```css
@import "stillwind/theme.css" layer(theme);
@import "stillwind/utilities.css" layer(utilities);
@import "stillwind/builtins.css";
```

```tsx
style("p-4");
```

## How to fix

- Import `stillwind/utilities.css`, which contains the slot, as in the example.
- Or write `@stillwind-slot utilities;` where the utilities should go.
- If you do not need a custom selection, import `stillwind` instead.

Other slots that a feature needs are reported as [SW14002](/docs/errors/SW14002).
