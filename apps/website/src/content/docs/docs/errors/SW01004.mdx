<CompilerError code="SW01004" category="configuration" />

This error occurs when `hashLength` is not an integer from 1 to 50. The setting
chooses the number of hash characters in generated names. The message shows the
value and the maximum.

## Reported

```ts
const project = { css: "./src/stillwind.css", files: ["src/**/*.tsx"], hashLength: 0 };
```

## Fixed

```ts
const project = { css: "./src/stillwind.css", files: ["src/**/*.tsx"], hashLength: 5 };
```

## How to fix

- Use an integer from 1 to 50. The default is 5.
- To shorten names, lower the value. To make collisions less likely, raise it.
- Use the same value in client and server builds that share styles.
