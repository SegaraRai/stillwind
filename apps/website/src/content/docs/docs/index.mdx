This guide adds Stillwind to a Vite application that uses React. At the end, a
button uses Stillwind styles, and the CLI checks them. For another framework or
build tool, follow the same steps and use the build setup from
[Framework integrations](/docs/frameworks/).

<Aside type="caution" title="Pre-alpha">
  Stillwind is in pre-alpha. Test your application's build and pages before you release changes.
</Aside>

## Install the packages

```sh
vp i stillwind
vp i -D @stillwind/integration @stillwind/cli
```

`stillwind` provides the style API. `@stillwind/integration` compiles your styles
during development and builds. `@stillwind/cli` checks your styles from the command line.

## Create a stylesheet

Create `src/stillwind.css`:

```css
@import "stillwind";

@theme {
  --color-accent: oklch(0.6 0.2 250);
}
```

`@import "stillwind"` loads the default Tailwind CSS v4 theme and utilities.
Each token in `@theme` adds utilities. For example, `--color-accent` adds
`bg-accent` and `text-accent`.

## Configure the project

Create `stillwind.config.ts` in the application root:

```ts
import { defineConfig } from "stillwind/config";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.{ts,tsx,vue,svelte,astro}"],
    },
  ],
});
```

`css` selects the stylesheet. `files` selects the files that the CLI and the
editor check.

<Aside type="note" title="Builds ignore files">
  The build compiles every module that your application imports, whether or not `files` matches it.
  The CLI and the language server (LSP) use `files` to find source files, including files that the
  application does not import.
</Aside>

Add Stillwind to `vite.config.ts`:

```ts
import { stillwind } from "@stillwind/integration/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite-plus";

export default defineConfig({
  plugins: [stillwind(), react()],
});
```

Place `stillwind()` before `react()`. Stillwind must compile styles before React
compiles JSX. The plugin finds `stillwind.config.ts` in the application root.

## Style a component

```tsx
import { style } from "stillwind/react";

export function SaveButton({ loading }: { loading: boolean }) {
  return (
    <button
      disabled={loading}
      {...style(
        "rounded-md bg-accent px-4 py-2 text-white hover:opacity-90",
        loading && "opacity-60",
      )}
    >
      Save changes
    </button>
  );
}
```

`style()` returns props, such as `className`, so you spread the result onto the
element. Each argument adds utilities. `loading && "opacity-60"` adds
`opacity-60` only while `loading` is true.

Start the development server. The button uses the accent color from your
stylesheet. The build writes the CSS for these utilities to a static CSS file.

## Check your styles

Change `bg-accent` to `bg-acent`, and run the CLI from the application root:

```sh
vp exec stillwind lint
```

The CLI reports `bg-acent` as an unknown utility. The build does not report this
mistake: the misspelled utility produces no CSS, and the page still renders.
Run the CLI in CI to catch such mistakes before you merge them.
