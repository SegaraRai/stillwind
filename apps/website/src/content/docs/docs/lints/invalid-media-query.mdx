<LintRuleSummary name="invalid-media-query" />

This rule reports an argument of `style.media()` that is not a media condition.
`hover:` matches a hovered element, not a property of the device, so it cannot
become a query for `matchMedia()`. The argument is left out, and when no argument
remains, the query is `not all`.

## Reported

```tsx
style.media("hover");
```

## Fixed

```tsx
style.media("pointer-fine");
```

## How to fix

- To check whether the device has a precise pointer, such as a mouse, use
  `pointer-fine`, as in the example.
- To check the viewport or user preferences, use media variants such as `md` or
  `motion-safe`.
- `supports-*` and container queries are not media conditions either.

See [style.media()](/docs/macros/media/#inputs).
