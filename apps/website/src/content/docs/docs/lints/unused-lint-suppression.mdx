<LintRuleSummary name="unused-lint-suppression" analysis="project" />

This rule reports a suppression comment that suppresses no finding, for example
because the code was fixed after the comment was added. The comment would hide a
future finding that nobody has reviewed. The `strict` preset enables this rule.

## Configuration

```json
{ "lint": { "rules": { "unknown-utility": "warn", "unused-lint-suppression": "warn" } } }
```

## Reported

```tsx
// swlint-disable-next-line unknown-utility
style("p-4");
```

## Fixed

```tsx
style("p-4");
```

## How to fix

Remove the comment, as in the example. If the rule should still report the line,
check that the comment is on the right line and names the right rule.
