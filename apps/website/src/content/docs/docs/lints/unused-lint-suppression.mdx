<LintRuleSummary name="unused-lint-suppression" analysis="project" />

This check needs the findings from the complete analysis run. A suppression
for an inactive or absent finding leaves an unnecessary exception in the source.

## Configuration

```json
{ "lint": { "rules": { "unknown-utility": "warn", "unused-lint-suppression": "warn" } } }
```

## Reported

```tsx
// swlint-disable-next-line unknown-utility
style("p-4");
```

## Accepted

```tsx
style("p-4");
```

Remove the obsolete directive after correcting the source. Preserve a suppression
only when the enabled rule still reports the intentional exception at that location.
