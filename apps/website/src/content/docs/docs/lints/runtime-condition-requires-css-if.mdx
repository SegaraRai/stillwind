<LintRuleSummary name="runtime-condition-requires-css-if" />

This rule reports a runtime CSS condition, such as `if(--state:active):`, that
the compiler can only express with the native CSS `if()` function. The project
does not enable it, so the utility produces no CSS.

## Reported

```tsx
style("if(--state:active):block");
```

## Fixed

```tsx
style("data-[state=active]:block");
```

## How to fix

- Set the state as an attribute, such as `data-state="active"`, and use an
  attribute variant, as in the example. This works in every browser.
- If the browsers that you support implement CSS `if()`, set `useCssIf: true` in
  the project, and keep the condition.

See [Configuration](/docs/configuration/#generated-css).
