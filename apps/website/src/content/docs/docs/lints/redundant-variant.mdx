<LintRuleSummary name="redundant-variant" />

This rule reports a variant that adds no condition, such as a second `hover:` in
`hover:hover:`. It also reports a variant that another variant in the stack
already implies.

## Reported

```tsx
style("hover:hover:p-4");
```

## Fixed

```tsx
style("hover:p-4");
```

## How to fix

Remove the extra variant, and keep the others. The automatic fix removes it.

Variants that can never match together are reported by
[unsatisfiable-variants](/docs/lints/unsatisfiable-variants/) instead.
