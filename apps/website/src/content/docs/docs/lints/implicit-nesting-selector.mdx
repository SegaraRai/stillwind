---
title: implicit-nesting-selector
description: Reports a custom variant selector without &, which matches descendants.
slug: docs/lints/implicit-nesting-selector
---

This rule reports a `@custom-variant` selector without `&`. Without `&`, the
selector matches descendants of the element, not the element itself. In the
example, `hocus:` would match hovered elements inside the element.

## Reported

<DiagnosticExample code="implicit-nesting-selector">

```css
@custom-variant hocus (:hover);
```

</DiagnosticExample>

## Fixed

```css
@custom-variant hocus (&:hover);
```

## How to fix

- Add `&` where the element belongs in the selector, as in the example.
- If the variant should match descendants, write that explicitly, such as
  `(& :hover)`.
