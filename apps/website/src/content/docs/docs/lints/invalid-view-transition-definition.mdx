This rule reports a `style.viewTransition()` definition that the compiler cannot
read, such as an unknown field. Each field must name a snapshot pseudo-element,
so an unknown field produces no CSS.

## Reported

<DiagnosticExample code="invalid-view-transition-definition">

```tsx
const transition = style.viewTransition({ before: "opacity-0" });
style(transition.for("card"));
```

</DiagnosticExample>

## Fixed

```tsx
const transition = style.viewTransition({ old: "opacity-0" });
style(transition.for("card"));
```

## How to fix

- Use the fields `group`, `imagePair`, `old`, and `new`. `old` styles the snapshot
  before the update, and `new` styles the snapshot after it.
- Write each field as a utility string literal.

See [style.viewTransition()](/docs/macros/view-transition#define-the-snapshot-styles).
