---
title: ineffective-anchor-scope
description: Reports an empty or repeated ref list in an anchor scope.
slug: docs/lints/ineffective-anchor-scope
---

This rule reports an anchor scope with an empty ref list, or with a ref listed
twice. An empty list sets no `anchor-scope`, and a repeated ref adds nothing.

## Reported

<DiagnosticExample code="ineffective-anchor-scope">

```tsx
style(style.anchorScope([]));
```

</DiagnosticExample>

## Fixed

```tsx
const trigger = style.ref("trigger");
style(style.anchorScope([trigger]));
```

## How to fix

Write the scope that you mean:

- List the refs whose anchor names this element limits, as in the example.
- Use `"all"` to limit every anchor name.
- Use `"none"` to set `anchor-scope: none`.

See [style.anchorScope()](/docs/macros/anchor-scope/#inputs).
