---
title: mismatched-framework-import
description: Reports an import of style() from the entrypoint of another framework.
slug: docs/lints/mismatched-framework-import
---

This rule reports a file that imports `style()` from the entrypoint of another
framework, such as `stillwind/astro` in a React component. Each entrypoint
returns props in the form of its framework, such as `className` for React.

## Reported

<DiagnosticExample code="mismatched-framework-import">

```tsx
import { style } from "stillwind/astro";

export const props = style("p-4");
```

</DiagnosticExample>

## Fixed

```tsx
import { style } from "stillwind/react";

export const props = style("p-4");
```

## How to fix

Import from the entrypoint of the framework that renders the element. A React
island inside an Astro page imports `stillwind/react`. See
[Framework integrations](/docs/integrations/#import-style-for-your-framework).
