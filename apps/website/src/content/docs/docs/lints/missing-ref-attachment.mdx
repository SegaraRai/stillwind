---
title: missing-ref-attachment
description: Reports asContainer() or asAnchor() in a call that does not attach the ref.
slug: docs/lints/missing-ref-attachment
---

This rule reports `asContainer()` or `asAnchor()` in a `style()` call that does not
also attach the ref. The container or anchor applies only to an element that has
the ref, so without it, nothing happens.

## Reported

<DiagnosticExample code="missing-ref-attachment">

```tsx
const card = style.ref("card");
style(card.asContainer("inline-size"));
```

</DiagnosticExample>

## Fixed

```tsx
const card = style.ref("card");
style(card, card.asContainer("inline-size"));
```

## How to fix

Pass the ref and the method in the same `style()` call, as in the example.

`positionAnchor()` is not reported. The positioned element does not need the ref.
