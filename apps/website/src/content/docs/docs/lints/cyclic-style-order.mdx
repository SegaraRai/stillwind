---
title: cyclic-style-order
description: Reports files that pass styles to components of each other, so their CSS order cannot follow both.
slug: docs/lints/cyclic-style-order
---

This rule reports a file whose CSS must come after another file's CSS, while
that file's CSS must also come after this file, directly or through other
files. A file must come after another file when it passes a `style()` result
to a component that the other file declares, or when it builds a style on a
base that the other file declares. See
[CSS ordering](/docs/concepts/css-ordering#files-that-pass-styles-to-components).

When the order forms a cycle, Stillwind keeps one of the orders, and the build
continues. The utilities that a caller passes to a component can then lose to
the component's own utilities.

## Reported

```tsx title="card.tsx"
import { style } from "stillwind/react";
import { Button } from "./button";

export function Card(props: CardProps) {
  return (
    <div {...style("rounded p-4", style.forward(props))}>
      <Button {...style("w-full")} />
    </div>
  );
}
```

```tsx title="button.tsx"
import { style } from "stillwind/react";
import { Card } from "./card";

export function Button(props: ButtonProps) {
  return <Card {...style("p-2", style.forward(props))} />;
}
```

`card.tsx` passes a style to `Button`, and `button.tsx` passes a style to
`Card`.

## How to fix

- Move one of the components to its own file, so that the files do not pass
  styles to each other.
- Or stop passing a style in one direction, for example by moving the
  utilities into the receiving component.
