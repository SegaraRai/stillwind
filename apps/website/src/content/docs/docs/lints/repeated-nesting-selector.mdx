<LintRuleSummary name="repeated-nesting-selector" />

This rule reports a selector variant that repeats `&`, such as `[&+&]:`, to relate
two elements. `&` stands for the generated class of the style, so the selector
matches any two elements that share the style. When the style is shared or used
as a base, it can match pairs that you did not mean.

## Reported

```tsx
style("[&+&]:mt-4");
```

## Fixed

```tsx
const list = style("flex flex-col gap-4");
const item = style("rounded-md p-4");
```

## How to fix

- To space items in a list, put `gap` on the list, as in the example.
- To style an element from the state of a sibling, use refs with
  [`.in()`](/docs/macros/ref/in/).
