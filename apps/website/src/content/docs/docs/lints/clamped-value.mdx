<LintRuleSummary name="clamped-value" />

This rule reports a literal value outside the range that the browser uses for the
property. The browser clamps the value to the range, so the extra amount has no
effect. For example, `opacity-150` behaves the same as `opacity-100`.

## Reported

```tsx
style("opacity-150");
```

## Fixed

```tsx
style("opacity-100");
```

## How to fix

Use the end of the range that the value reaches, as in the example, or a value
inside the range.

The rule checks values written in the code. It does not check values that a
custom property receives at runtime.
