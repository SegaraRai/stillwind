<LintRuleSummary name="invalid-css-input" />

This rule reports an argument of `style.css()` that the compiler cannot turn into
CSS at build time, such as a number, a runtime condition, a ref, or a stored
`style()` result. The argument adds nothing to the string.

## Reported

```tsx
style.css(42, { selector: ":host" });
```

## Fixed

```tsx
style.css("w-[42px]", { selector: ":host" });
```

## How to fix

- Write the style as utilities that are known at build time.
- For a value that changes at runtime, set a custom property on the element with
  JavaScript, and read it in a utility such as `w-(--width)`.

[style.css()](/docs/macros/css/#inputs) lists the accepted inputs.
