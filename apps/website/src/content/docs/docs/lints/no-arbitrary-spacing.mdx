<LintRuleSummary name="no-arbitrary-spacing" />

An arbitrary padding length bypasses the configured spacing scale. This policy
does not invalidate the CSS; the CLI reports the project restriction.

## Reported

```tsx
style("p-[13px]");
```

## Accepted

```tsx
style("p-3");
```

Use a scale value or define a named semantic spacing token. The `properties`
option adds property domains beyond the built-in margin, padding, and gap domains;
it does not replace those built-in domains.
