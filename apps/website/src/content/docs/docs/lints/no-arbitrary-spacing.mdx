<LintRuleSummary name="no-arbitrary-spacing" />

This rule reports margin, padding, or gap written as an arbitrary value, such as
`p-[13px]`. The CSS works, but the value is not on your spacing scale. No preset
enables this rule.

## Reported

```tsx
style("p-[13px]");
```

## Fixed

```tsx
style("p-3");
```

## How to fix

- Use the nearest value on the scale. With the default `--spacing` of `0.25rem`,
  `p-3` is 12px, as in the example.
- If the exact value has a role in your design, add a token, such as
  `--spacing-panel: 13px` in `@theme`, and use `p-panel`.

## Options

`properties` lists more CSS properties to check, in addition to margin, padding,
and gap.
