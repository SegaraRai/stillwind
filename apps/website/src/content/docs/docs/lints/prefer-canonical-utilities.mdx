<LintRuleSummary name="prefer-canonical-utilities" />

This rule reports a utility that your theme can write in a shorter, standard
form with the same CSS, such as `px-[16px]` for `px-4`. The standard form shows
that the value is on the scale.

## Reported

```tsx
style("px-[16px]");
```

## Fixed

```tsx
style("px-4");
```

## How to fix

Use the suggested form. The automatic fix applies it.

## Options

`pxToRem` compares `px` values with `rem` values by using `rootFontSize`. With the
default root size of 16px, `px-[16px]` matches `px-4`, which is `1rem`. Turn the
option off if your documents use another root size and you have not set
`rootFontSize`.
