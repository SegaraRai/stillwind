---
title: document-scoped-selector
description: Reports a selector variant that styles the whole document instead of the element.
slug: docs/lints/document-scoped-selector
---

This rule reports a variant that replaces the element with a document-wide
target, such as `[:root]:`. Stillwind compiles CSS statically, so including this
declaration in your code affects the document even when the element is not
rendered.

## Reported

<DiagnosticExample code="document-scoped-selector">

```tsx
style("[:root]:text-red-500");
```

</DiagnosticExample>

## Fixed

```css
:root {
  @apply text-red-500;
}
```

## How to fix

- To style the root of the page, write a rule in your stylesheet, as in the
  example.
- To style the element itself, remove the variant: `style("text-red-500")`.
