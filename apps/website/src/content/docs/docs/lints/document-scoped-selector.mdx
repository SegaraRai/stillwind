<LintRuleSummary name="document-scoped-selector" />

This rule reports a variant that replaces the element with a document-wide
target, such as `[:root]:`. The style then applies to the root of the page from
inside a component, and it no longer depends on the element that receives the
props.

## Reported

```tsx
style("[:root]:text-red-500");
```

## Fixed

```css
:root {
  @apply text-red-500;
}
```

## How to fix

- To style the root of the page, write a rule in your stylesheet, as in the
  example.
- To style the element itself, remove the variant: `style("text-red-500")`.
