title: invalid-recipe-config
description: Reports an unknown or malformed field in a style.recipe() configuration.

This rule reports a `style.recipe()` configuration that the compiler cannot read,
such as an unknown field, a default for an option that does not exist, or a
configuration that is not written in the call. The factory ignores the invalid
part.

## Reported

<DiagnosticExample code="invalid-recipe-config">

```tsx
style.recipe("p-4", {
  variant: {
    size: {
      small: "p-2",
    },
  },
});
```

</DiagnosticExample>

## Fixed

```tsx
style.recipe("p-4", {
  variants: {
    size: {
      small: "p-2",
    },
  },
});
```

## How to fix

- Use the fields `variants`, `defaultVariants`, and `compoundVariants`.
- Write the configuration as an object literal in the call.
- In `defaultVariants` and `compoundVariants`, use only options and values that
  `variants` declares.

See [`style.recipe()`](/docs/macros/recipe#configuration).
