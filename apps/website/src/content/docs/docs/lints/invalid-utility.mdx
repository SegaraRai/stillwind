title: invalid-utility

This rule reports a utility whose name is known but whose form is not valid. For
example, `flex` has no negative form, so `-flex` is invalid. The utility produces
no CSS.

## Reported

<DiagnosticExample code="invalid-utility">

```tsx
style("-flex");
```

</DiagnosticExample>

## Fixed

```tsx
style("flex");
```

## How to fix

- Remove the modifier or value that the utility does not accept.
- Check the accepted forms in [Built-in utilities](/docs/utilities/).

A utility name or theme value that does not exist is reported by
[unknown-utility](/docs/lints/unknown-utility/) instead.
