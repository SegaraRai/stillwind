---
title: duplicate-definition
description: Reports a utility or variant definition that replaces an earlier one with the same name.
slug: docs/lints/duplicate-definition
---

This rule reports a `@utility` or `@custom-variant` definition that replaces an
earlier definition with the same name. The definitions do not combine, so the
earlier one is lost. In the example, `hocus` matches focus only, not hover.

## Reported

<DiagnosticExample code="duplicate-definition">

```css
@custom-variant hocus (&:hover);
@custom-variant hocus (&:focus);
```

</DiagnosticExample>

## Fixed

```css
@custom-variant hocus (&:hover, &:focus);
```

## How to fix

- To combine the definitions, write them as one definition, as in the example.
- If one of the definitions is left over, remove it.
