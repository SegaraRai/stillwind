<LintRuleSummary name="bypassed-undefinition" />

This rule reports a top-level `@utility` that also applies where Stillwind
removes the utility on purpose. Inside animation options, for example,
`duration-*` sets `animation-duration`, and the built-in definitions remove the
`transition-duration` meaning there. A top-level `duration-slow` would bring that
meaning back.

## Reported

```css
@utility duration-slow {
  transition-duration: 1s;
}
```

## Fixed

```css
@stillwind-registry default {
  @utility duration-slow {
    transition-duration: 1s;
  }
}
```

## How to fix

Define the utility inside `@stillwind-registry default`, as in the example. Then
it applies in ordinary `style()` calls, and animation options keep their own
meaning of `duration-*`.
