---
title: ambiguous-style-base-order
description: Reports two independent base styles in one call that set the same property.
slug: docs/lints/ambiguous-style-base-order
---

This rule reports a `style()` call with two base styles that set the same
property, when neither base is built on the other. The order of the arguments
does not decide which base wins, so the result is not defined.

## Reported

<DiagnosticExample code="ambiguous-style-base-order">

```tsx
const first = style("p-2");
const second = style("p-4");
export const props = style(first, second);
```

</DiagnosticExample>

## Fixed

```tsx
const first = style("p-2");
const second = style(first, "p-4");
export const props = style(second);
```

## How to fix

- Build the overriding base on the other one, as in the example. Then its
  utilities always win.
- Or remove the property from one of the bases.

Bases that set different properties do not need this.
