This rule reports a Tailwind CSS feature in your stylesheet that Stillwind
ignores, such as `@config` or an option on `@import`. Stillwind reads these
settings from `stillwind.config.ts`, so the line has no effect.

## Reported

<DiagnosticExample code="ignored-tailwind-feature">

```css
@config "./tailwind.config.js";
```

</DiagnosticExample>

## Fixed

```ts title="stillwind.config.ts"
import { defineConfig } from "stillwind/config";

import tailwindConfig from "./tailwind.config.js";

export default defineConfig({
  projects: [
    {
      css: "./src/stillwind.css",
      files: ["src/**/*.{ts,tsx}"],
      tailwind: tailwindConfig,
    },
  ],
});
```

## How to fix

- Move the configuration to the `tailwind` field of the project in
  `stillwind.config.ts`, as in the example, and remove `@config`.
- Move an `important` option on `@import` to the `important` field.
- [Migrating from Tailwind CSS](/docs/guides/migrating-from-tailwind#move-configuration)
  lists every replacement.
