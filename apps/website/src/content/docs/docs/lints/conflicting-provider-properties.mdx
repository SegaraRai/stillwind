title: conflicting-provider-properties
description: Reports a container or anchor property that a ref method and a utility both set.

---

This rule reports a container or anchor property that a ref method, such as
`asContainer()`, and another utility both set on the same element. For example,
`asContainer("size")` sets `container-type: size`, and `@container` sets it to
`inline-size`. Only one value takes effect, and the code does not show which.

## Reported

<DiagnosticExample code="conflicting-provider-properties">

```tsx
const card = style.ref("card");
style(card, card.asContainer("size"), "@container");
```

</DiagnosticExample>

## Fixed

```tsx
const card = style.ref("card");
style(card, card.asContainer("size"));
```

## How to fix

- Set the property in one place. With a ref, pass the container type to
  `asContainer()`, and remove the utility, as in the example.
- If you want the type from the utility, call `asContainer()` without a type.
