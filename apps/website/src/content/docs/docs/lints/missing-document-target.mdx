---
title: missing-document-target
description: Reports a style.css() utility without a selector to apply to.
slug: docs/lints/missing-document-target
---

This rule reports a utility in `style.css()` that has no element to style.
`style.css()` returns a stylesheet, not props for an element, so a utility needs
a `selector` option or a variant that sets its own selector. Otherwise the utility
produces no CSS.

## Reported

<DiagnosticExample code="missing-document-target">

```tsx
style.css("p-4");
```

</DiagnosticExample>

## Fixed

```tsx
style.css("p-4", { selector: ":host" });
```

## How to fix

- Add a `selector` option, such as `:host` for the shadow host.
- Or use a variant that sets its own selector, such as `host:p-4`.

See [style.css()](/docs/macros/css#inputs).
