<LintRuleSummary name="invalid-view-transition-use" />

This rule reports a `.for()` call with more than one argument, or with a key that
is not a string or a number. One `.for()` call names one element, so extra
arguments do not name more elements.

## Reported

```tsx
const transition = style.viewTransition({ old: "duration-150" });
style(transition.for("a", "b"));
```

## Fixed

```tsx
const transition = style.viewTransition({ old: "duration-150" });
const first = style(transition.for("a"));
const second = style(transition.for("b"));
```

## How to fix

- Give each element its own `.for()` call with its own key, as in the example.
- Use a string or a number as the key, such as the ID of the item.

See [style.viewTransition()](/docs/macros/view-transition/#name-the-element).
