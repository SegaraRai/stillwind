This rule reports utilities that are not in the order that `stillwind fmt` uses.
The order does not change the CSS. A consistent order makes utilities easier to
read and diffs smaller. The `stylistic` preset enables this rule.

## Reported

<DiagnosticExample code="prefer-sorted-utilities">

```tsx
style("px-4 flex");
```

</DiagnosticExample>

## Fixed

```tsx
style("flex px-4");
```

## How to fix

Run `stillwind fmt`, or `stillwind lint --fix` with this rule enabled. The editor
also sorts on save with `source.sort.stillwind`.

`stillwind fmt` sorts even when this rule is off. To stop all sorting, set
`sort: false`. See [Sorting](/docs/configuration/#sorting).
