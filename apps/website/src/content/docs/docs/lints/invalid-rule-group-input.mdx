<LintRuleSummary name="invalid-rule-group-input" />

This rule reports a `class` field, a custom property, a ref, or a stored `style()`
result inside an object with variant keys, such as `{ "hover:": ... }`. A variant
can only condition utilities, so the input is left out.

## Reported

```tsx
style({ "hover:": { class: "external" } });
```

## Fixed

```tsx
declare const hovered: boolean;
style(hovered && { class: "external" });
```

## How to fix

- To add a class from another stylesheet in a state, decide the state in
  JavaScript and pass the `class` field under that condition, as in the example.
- If the class only applies styles that Stillwind has as utilities, write those
  utilities under the variant instead, such as `{ "hover:": "opacity-50" }`.
