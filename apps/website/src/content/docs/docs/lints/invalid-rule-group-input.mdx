<LintRuleSummary name="invalid-rule-group-input" />

CSS variant groups contain rules. External classes do not become conditional
CSS declarations, so a `class` input inside a group is omitted.

## Reported

```tsx
style({ "hover:": { class: "external" } });
```

## Accepted

```tsx
style({ class: "external", "hover:": "opacity-50" });
```

Keep external classes at the root. Use a JavaScript condition around the root
class input when its presence must depend on application state.
