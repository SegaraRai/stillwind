<LintRuleSummary name="invalid-keyframes-use" />

This rule reports an animation that you apply with an argument other than a
string literal of options, such as a number. The compiler cannot read the
argument, so the animation gets no options.

## Reported

```tsx
const fade = style.keyframes({ to: "opacity-100" });
style(fade(42));
```

## Fixed

```tsx
const fade = style.keyframes({ to: "opacity-100" });
style(fade("duration-[42ms]"));
```

## How to fix

- Write the options as utilities in a string literal, such as
  `"duration-300 ease-out"`.
- Write a duration as a utility, such as `duration-300` or `duration-[42ms]`.

A string that contains a utility that is not an animation option is reported by
[invalid-animation-option](/docs/lints/invalid-animation-option/) instead.
