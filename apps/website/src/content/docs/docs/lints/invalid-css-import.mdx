This rule reports an `@import` in your stylesheet that the integration cannot
resolve, such as a misspelled package name or a missing file. The import adds
nothing.

## Reported

<DiagnosticExample code="invalid-css-import">

```css
@import "stilwind";
```

</DiagnosticExample>

## Fixed

```css
@import "stillwind";
```

## How to fix

- Check the spelling of the package name, and that the package is installed.
- Write a file path relative to the stylesheet that imports it, and check that
  the file exists.
- For a package stylesheet, check that the package exports that path.
