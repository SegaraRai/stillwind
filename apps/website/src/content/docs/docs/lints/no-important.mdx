---
title: no-important
description: Reports utilities with the important modifier, such as p-4!.
slug: docs/lints/no-important
---

This rule reports each use of a utility with the `!` modifier once, even when it
emits several important declarations. It also reports `!important` declarations
in utility definitions. An important declaration wins over styles that would
normally override it, which makes later changes harder. No preset enables this rule.

## Reported

<DiagnosticExample code="no-important">

```tsx
const base = style("p-2");
style(base, "p-4!");
```

</DiagnosticExample>

## Fixed

```tsx
const base = style("p-2");
style(base, "p-4");
```

## How to fix

- To override a shared style, pass it as a base. The later utilities win without
  `!`, as in the example.
- To win over a stylesheet that you do not control, use the `important` field of
  the project instead. See [Configuration](/docs/configuration/#generated-css).
