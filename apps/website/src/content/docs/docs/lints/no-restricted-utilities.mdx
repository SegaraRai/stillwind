<LintRuleSummary name="no-restricted-utilities" />

This rule reports a utility whose name matches a pattern that your project
forbids. It checks the name as written, not the generated CSS. The rule is off
until you list utilities.

## Configuration

```json
{
  "lint": {
    "rules": {
      "no-restricted-utilities": {
        "severity": "warn",
        "utilities": [{ "pattern": "space-*", "message": "Use gap on the container." }]
      }
    }
  }
}
```

## Reported

```tsx
style("flex flex-col space-y-4");
```

## Fixed

```tsx
style("flex flex-col gap-4");
```

## How to fix

Follow the message of the matching entry. In the example, the project prefers
`gap` to `space-*`, so the fix keeps the same spacing with `gap-4`.

## Options

`utilities` lists entries with a name `pattern` and an optional `message`.
Patterns accept `*` and `?`, and they are case-sensitive.

To also catch other utilities that produce the same CSS, use
[no-restricted-declarations](/docs/lints/no-restricted-declarations/).
