This rule reports `group-*` and `peer-*` variants. They connect elements through
the class names `group` and `peer`, so any element with the same class can
match, and nothing checks a misspelled name. A ref connects the elements through a
variable instead. The `stylistic` preset enables this rule.

## Reported

<DiagnosticExample code="prefer-typed-relationships">

```tsx
style("group-hover:text-red-500");
```

</DiagnosticExample>

## Fixed

```tsx
const card = style.ref("card");
const container = style(card);
const title = style({ [card("hover")]: "text-red-500" });
```

## How to fix

- Replace `group` with a ref on the parent, and `group-hover:` with a condition on
  that ref, as in the example.
- Replace `peer` with a ref on the sibling, and use
  [`.in()`](/docs/macros/ref/in/) with a ref on a shared ancestor.

See [Element relationships](/docs/guides/element-relationships/).
