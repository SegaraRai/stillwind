---
title: unverified-style-base
description: Reports a base style whose source the CLI cannot find from its type.
slug: docs/lints/unverified-style-base
---

This rule reports a base style whose type does not show which `style()` call
created it, such as a value declared as `ReturnType<typeof style>`. The compiler
cannot find the CSS of the base, so it cannot order the later utilities after it.

## Project files

```ts title="globals.d.ts"
declare module "virtual:styles" {
  import { style } from "stillwind/react";

  export const base: ReturnType<typeof style>;
}
```

```ts title="styles.ts"
import { style } from "stillwind/react";

export const base = style("rounded-md");
```

## Reported

<DiagnosticExample code="unverified-style-base">

```tsx
import { base } from "virtual:styles";

export const props = style(base, "p-4");
```

</DiagnosticExample>

## Fixed

```tsx
import { base } from "./styles";

export const props = style(base, "p-4");
```

## How to fix

- Import the base from the source module that calls `style()`, as in the example.
- Keep the type that TypeScript infers when you export a style. A type annotation
  such as `ReturnType<typeof style>` hides the source.
