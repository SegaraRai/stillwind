<LintRuleSummary name="unknown-variant" />

This rule reports a variant that your stylesheet does not define, such as a
misspelled `hovr:`. The condition never matches, so the utilities under it never
apply.

## Reported

```tsx
style("hovr:p-4");
```

## Fixed

```tsx
style("hover:p-4");
```

## How to fix

- Correct the spelling of the variant.
- To use a variant of your own, define it with `@custom-variant` in your
  stylesheet.
