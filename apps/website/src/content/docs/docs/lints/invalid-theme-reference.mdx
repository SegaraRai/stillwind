<LintRuleSummary name="invalid-theme-reference" />

This stylesheet reference names an inactive token without a fallback. The
receiving declaration cannot resolve and is omitted.

## Reported

```css
.card {
  color: --theme(--color-missing);
}
```

## Accepted

```css
.card {
  color: --theme(--color-missing, blue);
}
```

Define the intended token or provide a fallback. Malformed `--theme()` syntax has
a separate fatal contract, [SW14007](/docs/errors/SW14007/).
