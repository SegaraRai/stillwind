<LintRuleSummary name="incompatible-theme-value" />

The color namespace expects a color. A length can be retained as authored theme
data while still being incompatible with the namespace's declared domain.

## Reported

```css
@theme {
  --color-brand: 1rem;
}
```

## Accepted

```css
@theme {
  --color-brand: blue;
}
```

Move the value to the appropriate namespace or correct its type. For a variable
whose utility family has several types, also consider [prefer-typed-variables](/docs/lints/prefer-typed-variables/).
