<LintRuleSummary name="incompatible-theme-value" />

This rule reports a theme token whose value does not match the type of its
namespace. For example, tokens in `--color-*` must be colors, so a length makes
`bg-brand` and the other color utilities write an invalid value.

## Reported

```css
@theme {
  --color-brand: 1rem;
}
```

## Fixed

```css
@theme {
  --spacing-brand: 1rem;
}
```

## How to fix

- If the value is right, move the token to the namespace of that type, such as
  `--spacing-*` for a length, as in the example.
- If the namespace is right, correct the value, such as a color for `--color-*`.
