<LintRuleSummary name="no-restricted-declarations" />

This rule reports a utility that produces a CSS declaration that your project
forbids. It checks the generated declarations, so it also catches other
utilities and arbitrary values that produce the same declaration. The rule is off
until you list declarations.

## Configuration

```json
{
  "lint": {
    "rules": {
      "no-restricted-declarations": {
        "severity": "warn",
        "rules": [{ "properties": ["transition-property"], "values": ["all"] }]
      }
    }
  }
}
```

## Reported

```tsx
style("transition-all");
```

## Fixed

```tsx
style("transition-colors");
```

## How to fix

Use a utility that produces an allowed declaration. In the example, the project
forbids transitions on every property, so the fix names the properties that
change.

## Options

`rules` lists the restrictions. Each entry has `properties` and `values`
patterns, and an optional `message` that explains what to use instead. Patterns
accept `*` and `?` and ignore case. Every matching entry applies.
