<LintRuleSummary name="no-restricted-declarations" />

The rule checks resolved declarations rather than one authored utility name.
Property and serialized-value patterns ignore ASCII case. Every matching restriction applies.

## Configuration

```json
{
  "lint": {
    "rules": {
      "no-restricted-declarations": {
        "severity": "warn",
        "rules": [{ "properties": ["position"], "values": ["absolute"] }]
      }
    }
  }
}
```

## Reported

```tsx
style("absolute");
```

## Accepted

```tsx
style("relative");
```

Both property and value patterns belong to the receiving CSS domain. Use the
optional message to explain the component or design rule that authors should follow.
