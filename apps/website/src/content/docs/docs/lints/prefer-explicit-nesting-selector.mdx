<LintRuleSummary name="prefer-explicit-nesting-selector" />

A custom variant selector without `&` nests as a descendant. If the intent is
the styled element's own state, omitting the subject expresses a different relationship.

## Reported

```css
@custom-variant hocus (:hover);
```

## Accepted

```css
@custom-variant hocus (&:hover);
```

Include `&` where the utility subject belongs. Keep a descendant selector only
when descendant matching is intentional.
