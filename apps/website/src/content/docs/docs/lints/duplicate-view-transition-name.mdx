---
title: duplicate-view-transition-name
description: Reports two .for() calls in one style() call.
slug: docs/lints/duplicate-view-transition-name
---

This rule reports a `style()` call with more than one `.for()`. An element has one
`view-transition-name`, so only one of the names takes effect.

## Reported

<DiagnosticExample code="duplicate-view-transition-name">

```tsx
const transition = style.viewTransition({ old: "duration-150" });
style(transition.for("a"), transition.for("b"));
```

</DiagnosticExample>

## Fixed

```tsx
const transition = style.viewTransition({ old: "duration-150" });
style(transition.for("a"));
```

## How to fix

- Keep one `.for()` for the element, as in the example.
- If the names belong to different elements, give each element its own
  `style()` call with its own `.for()`.
- To combine several transitions on one element, pass the others without
  `.for()`, such as `style(fade, slide.for("a"))`.
