<LintRuleSummary name="invalid-runtime-condition" />

This rule reports a runtime CSS condition, such as `--if()`, that the compiler
cannot compile where you wrote it. Some comparisons need the native CSS `if()`
function, and some positions, such as a keyframe, do not support the condition at
all. The declaration produces no CSS.

## Reported

```tsx
const fade = style.keyframes({ to: "[color:--if(--mode:compact,red,blue)]" });
style(fade("duration-300"));
```

## Fixed

```tsx
declare const compact: boolean;
const red = style.keyframes({ to: "text-red-500" });
const blue = style.keyframes({ to: "text-blue-500" });
style((compact ? red : blue)("duration-300"));
```

## How to fix

- Decide the condition in JavaScript, and choose between complete styles, as in
  the example.
- If the browsers that you support implement CSS `if()`, set `useCssIf: true` in
  the project. Then the compiler emits the native function.

A condition that only needs `useCssIf` is reported by
[runtime-condition-requires-css-if](/docs/lints/runtime-condition-requires-css-if/)
instead.
