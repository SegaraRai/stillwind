<LintRuleSummary name="invalid-runtime-condition" />

The condition grammar, its declaration context, and `useCssIf` determine whether
a runtime CSS test can lower. This keyframe value requests an unsupported
comparison under the default fallback mode.

## Reported

```tsx
const fade = style.keyframes({ to: "[color:--if(--mode:compact,red,blue)]" });
style(fade("duration-300"));
```

## Accepted

```tsx
const fade = style.keyframes({ to: "text-red-500" });
style(fade("duration-300"));
```

The accepted input removes the computed comparison. Do not assume that changing
severity restores it. Ordinary candidate syntax failures use
[invalid-utility](/docs/lints/invalid-utility/) or [invalid-variant](/docs/lints/invalid-variant/).
