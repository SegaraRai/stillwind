<LintRuleSummary name="invalid-style-input" />

This rule reports an argument of `style()` that the compiler cannot compile, such
as a number or a `style()` call written inside another `style()` call. The
argument adds nothing to the element.

## Reported

```tsx
style(42);
```

## Fixed

```tsx
style("w-(--width)", { "--width": "42px" });
```

## How to fix

- For a value that you know when you write the code, use a utility, such as
  `w-[42px]` or a theme value.
- For a value that changes at runtime, set a custom property and read it in a
  utility, as in the example.
- Store a `style()` result in a variable before you pass it to another call.

[style()](/docs/macros/style/#inputs) lists the accepted inputs.
