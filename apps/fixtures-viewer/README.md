# Stillwind fixtures viewer

[Stillwind](https://stillwind.dev/) compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when AI agents write much of it.

This package contains Stillwind's private read-only viewer for representative compiler output, CSS,
diagnostics, and source maps.

See [Review fixtures](../../docs/test-inventory.md#review-fixtures) for running the
viewer and [Fixture development](../../fixtures/projects/DEVELOPMENT.md) for case authoring.
