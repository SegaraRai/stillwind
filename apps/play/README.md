# Stillwind Play

Stillwind compiles Tailwind CSS v4 utilities into component props and static CSS.
It uses theme rules and compiler checks to keep styling code in order, even when
AI agents write much of it.

This package contains Stillwind's private static playground for editing projects,
inspecting diagnostics, and previewing React components.

See [Development](DEVELOPMENT.md) for local tasks, hosting, and editor contracts.
